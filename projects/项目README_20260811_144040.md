# 王秋月AI智能助手

> 一个集智能对话、任务管理与知识问答于一体的个性化AI助手，致力于为用户提供高效、自然、贴心的交互体验。

---

## 📖 简介

**王秋月AI智能助手** 是一款基于大语言模型（LLM）的智能对话应用，以“王秋月”为虚拟人格，具备自然语言理解、上下文记忆、多轮对话、任务规划与执行等能力。无论是日常闲聊、工作辅助、学习答疑，还是生活提醒，它都能快速响应，成为您的专属智能伙伴。

项目采用前后端分离架构，支持Web端与API接入，可灵活部署到个人服务器或云端，数据完全可控，隐私安全有保障。

---

## ✨ 功能特性

- **智能对话**：支持多轮自然语言交互，理解上下文，回答连贯自然。
- **个性化人格**：内置“王秋月”角色设定，语气亲切、逻辑清晰，可自定义人设。
- **任务管理**：支持创建待办事项、设置提醒、查询日程，帮助高效管理时间。
- **知识问答**：内置知识库检索，可回答百科、技术、生活等多领域问题。
- **文件解析**：支持上传文本/PDF/Word等文件，提取内容并进行摘要或问答。
- **语音交互**（可选）：集成语音识别与合成，实现语音对话。
- **插件扩展**：预留插件接口，可接入天气、新闻、计算器等第三方工具。
- **多端适配**：响应式Web界面，支持PC、平板与手机访问。

## 🛠️ 技术栈

| 层次       | 技术选型                                                                 |
|------------|--------------------------------------------------------------------------|
| **前端**   | Vue 3 + TypeScript + Vite + Element Plus + Pinia                         |
| **后端**   | Python 3.10+ / FastAPI（或 Node.js + Express）                           |
| **LLM接入**| OpenAI API / 通义千问 / 本地Ollama（支持自定义模型）                     |
| **数据库** | SQLite（默认）/ PostgreSQL（生产环境）                                   |
| **缓存**   | Redis（会话缓存与限流）                                                  |
| **部署**   | Docker + Docker Compose / Nginx                                          |
| **其他**   | LangChain（可选）、WebSocket（实时通信）、JWT（身份认证）                |

## 🚀 快速开始

### 环境要求

- Python 3.10+ 或 Node.js 16+
- Node.js 18+（前端构建）
- Docker（可选，用于容器化部署）
- 一个LLM API Key（如OpenAI、通义千问）或本地Ollama服务

### 1. 克隆项目

```bash
git clone https://github.com/yourusername/wangqiuyue-ai-assistant.git
cd wangqiuyue-ai-assistant
```

### 2. 后端启动（以FastAPI为例）

```bash
# 进入后端目录
cd backend

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env，填入你的API Key与数据库配置

# 启动服务
uvicorn main:app --reload --port 8000
```

### 3. 前端启动

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

浏览器访问 `http://localhost:5173` 即可开始使用。

### 4. 使用Docker（可选）

```bash
# 构建并启动所有服务
docker-compose up -d
```

### 5. 验证

- 打开前端页面，输入任意问题，如“你好，介绍一下你自己”。
- 若返回“你好！我是王秋月，你的AI助手……”则说明配置成功。
